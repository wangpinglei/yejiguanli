生态圈订单同步 API 对接文档

业绩管理系统 · 订单同步接口 · v1.0

概述： 本文档描述了生态圈系统向业绩管理系统推送订单数据的 API 接口。 生态圈系统通过 HTTP POST 请求将订单数据推送到本系统，系统自动去重并存储。 前端页面每 30 秒自动拉取最新同步订单，也可手动刷新。

1. 基础信息

项目说明
服务器地址http://<服务器IP>:5180
接口前缀/api
数据格式JSON（Content-Type: application/json）
认证方式请求头 X-API-Key: eco-sync-2026-secret
字符编码UTF-8
⚠️ 注意： API Key 为 eco-sync-2026-secret，请妥善保管。 生产环境部署前请修改 server/spa-server.js 中的 API_KEY 常量。

2. 接口列表

2.1 推送订单（核心接口）

POST /api/sync-orders 需 API Key

生态圈调用此接口推送一条或多条订单数据。系统按 orderId 自动去重，已存在的订单会被更新。

请求头

Header必填说明
Content-Type是application/json
X-API-Key是认证密钥：eco-sync-2026-secret

请求体格式

支持两种格式：单条订单 或 批量订单。

订单字段说明

字段名类型必填说明
orderIdstring是生态圈订单号（唯一标识，用于去重和更新）
orderDatestring是订单日期，格式 YYYY-MM-DD（如 2026-08-03）
salesUnitNamestring否销售单位名称（系统按名称自动匹配，如 "华东销售部"）
salesPersonNamestring否销售人员姓名（系统按姓名自动匹配）
productNamestring否产品名称（系统按名称自动匹配）
quantitynumber否销售数量，默认 1
unitPricenumber否单价（元）
totalAmountnumber否订单总金额（元）。如不传，自动计算 = quantity × unitPrice
customerNamestring否客户名称
remarkstring否备注信息，默认 "生态圈同步"

示例 1：推送单条订单

POST /api/sync-orders
Content-Type: application/json
X-API-Key: eco-sync-2026-secret

{
  "orderId": "ECO20260803001",
  "orderDate": "2026-08-03",
  "salesUnitName": "华东销售部",
  "salesPersonName": "张三",
  "productName": "智能终端Pro",
  "quantity": 10,
  "unitPrice": 5000,
  "totalAmount": 50000,
  "customerName": "杭州科技有限公司",
  "remark": "季度大客户订单"
}

2.2 查询已同步订单

GET /api/synced-orders 无需认证

查询已同步的订单列表，支持按月份和单位名称筛选。

查询参数

参数类型说明
yearMonthstring按月份筛选，格式 YYYY-MM（如 2026-08）
salesUnitNamestring按销售单位名称筛选

示例

GET /api/synced-orders?yearMonth=2026-08

// 响应
{
  "success": true,
  "count": 5,
  "orders": [
    {
      "id": "sync_1234567890_abc123",
      "externalOrderId": "ECO20260803001",
      "synced": true,
      "salesUnitName": "华东销售部",
      "salesPersonName": "张三",
      "productName": "智能终端Pro",
      "quantity": 10,
      "unitPrice": 5000,
      "totalAmount": 50000,
      "saleDate": "2026-08-03",
      "customerName": "客户A",
      "remark": "生态圈同步",
      "syncedAt": "2026-08-03T10:30:00.000Z"
    }
  ]
}

2.3 删除单条同步订单

DELETE /api/synced-orders/:id 需 API Key

按同步订单的 id 或 externalOrderId 删除。

DELETE /api/synced-orders/ECO20260803001
X-API-Key: eco-sync-2026-secret

// 响应
{ "success": true, "message": "已删除", "remaining": 4 }

2.4 清空所有同步订单

DELETE /api/synced-orders/clear 需 API Key 
DELETE /api/synced-orders/clear
X-API-Key: eco-sync-2026-secret

// 响应
{ "success": true, "message": "已清空所有同步订单" }

3. 名称匹配规则

同步订单推送后，系统会自动将订单中的名称匹配到系统中已有的数据：

  • 销售单位：按 salesUnitName 与系统中销售单位名称精确匹配或包含匹配
  • 销售人员：按 salesPersonName 与系统中人员姓名精确匹配
  • 产品：按 productName 与系统中产品名称精确匹配或包含匹配

匹配成功后，该订单将参与薪资提成计算和成本利润分析。
未匹配的订单仍会显示在销售记录列表中（标注"未匹配"），但不会参与薪资计算。超管可在系统中查看并处理未匹配的订单。

5. 对接流程建议

步骤操作负责人
1确认服务器 IP 和端口（默认 5180）可从生态圈服务器访问运维
2在生态圈系统中配置 API 地址和 API Key生态圈开发
3生态圈订单创建/支付成功后，调用 POST /api/sync-orders 推送订单生态圈开发
4在本系统中确认单位名称、人员姓名、产品名称与生态圈一致业绩系统管理员
5在销售记录页面验证同步订单是否正确显示和匹配业绩系统管理员
6验证薪资计算、成本分析是否正确包含同步订单业绩系统管理员
⚠️ 注意事项：
  • 确保生态圈推送的 salesUnitName、salesPersonName、productName 与本系统中的名称保持一致，否则无法自动匹配
  • 同一 orderId 重复推送会更新已有记录，不会产生重复
  • 同步订单在前端为只读，不可手动编辑或删除（可通过 API 删除）
  • 数据存储在服务器 server/data/synced-orders.json 文件中
