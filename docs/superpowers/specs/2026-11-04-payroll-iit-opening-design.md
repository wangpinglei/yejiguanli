# 个税周期期初（2025-12～2026-09）

## 目的

系统无 2025-12～2026-09 完整录入时，在人员 `taxProfile` 按周期写入三项期初，供 **2026-10 及之后**（同一周期内至 2026-11）累计预扣使用。

## 期初字段（截至 2026-09）

| 字段 | 含义 |
|---|---|
| `taxPaid` | 已预扣个税 B |
| `taxBase` | 累计扣税基数 Σ(应发−个人社保−个人公积金) |
| `taxable` | 应纳税所得额 C；`null` 表示不手填、由公式推 |

存于 `taxProfile.iitCycleOpenings['2025-12']`，含 `throughYm: '2026-09'`。

## 本月个税（10 月起）

- 往期税基：期初 `taxBase` + 仅累加 `throughYm` 之后、早于本月的（应发−个人社保−个人公积金）  
- **`C`（应纳税所得额）= 截至上月累计扣税基数 + 本期应发工资**  
- 本月应扣 = `max(f(C) − B', 0)`，`f` 为预扣率表；`B'` = 期初 B + 期后已扣个税  

## UI

个税步骤在核算月 `> 2026-09` 且周期起点为 `2025-12` 时展示三列可编辑，保存到档案。
